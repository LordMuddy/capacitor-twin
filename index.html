改变板间距 d，电容值如何变化？QUESTION 02

结论：C 与 d 成 反比 —— d 增大，C 减小；d 减小，C 增大。

C = ε₀εrS / d

固定 S 与 εr、只拖动 d 时，右侧 C 的读数与 C–d 曲线上的红点同步移动，轨迹是一条双曲线。

—
  • d 加倍 → C 减半；d 减半 → C 加倍（如 2 mm ↔ 4 mm）。
  • 接通电源（U 恒定）：E = U/d 随 d 增大而减小，Q = CU 也减小。
  • 断开电源（Q 恒定）：U = Q/C = Qd/(ε₀S) 随 d 线性增大，而 E = U/d = Q/(ε₀S) 与 d 无关。
  • 理想模型中 d → 0 时 C → ∞；实际受介质击穿、板面不平与边缘效应限制。

代码中的核心物理公式QUESTION 03

定义式C = Q / U
决定式C = ε₀εrS / d
场强E = U / d = σ / ε₀
电荷能量Q = CU，W = ½CU² = Q²/2C
能量密度w = ½ε₀εrE²

ε₀ = 8.854×10⁻¹² F/m；S 为极板正对面积（m²）；d 为板间距（m）；εr 为相对介电常数（空气 ≈ 1）。平台按匀强场、忽略边缘效应计算。
